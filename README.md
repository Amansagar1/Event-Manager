# Mini Event Manager

Welcome! This is a simple Event Manager app built with Next.js, Zustand, and TailwindCSS — designed to help you add, view, search, and delete your upcoming events.

---

## Getting Started

If you want to run this project locally, just follow these quick steps:

1. **Clone the repository:**

   ```bash
   git clone https://github.com/Amansagar1/Event-Manager.git
   cd Event-Manager
   pnpm install
   pnpm dev
